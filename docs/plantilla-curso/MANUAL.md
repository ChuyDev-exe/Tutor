# Manual de configuración

## Requisitos
| Herramienta | Versión mínima | Para qué |
|---|---|---|
| `python3` | 3.8 | Ejecutar tus soluciones y las pruebas |

## Instalación
- **macOS:** `brew install python`
- **Linux:** `sudo apt install python3`
- **Windows:** `winget install Python.Python.3`

## Preparar el entorno
1. Ejecuta **Tutor: Verificar requisitos del curso**.
2. (Opcional) **Tutor: Ejecutar setup del curso**.

## Problemas comunes
- «python3 no encontrado»: reinicia el editor tras instalar para refrescar el PATH.
