# Prepara tu entorno

Cada curso declara las herramientas que necesita (por ejemplo `gcc` o `python3`). Tutor IDE las comprueba y te dice cómo instalarlas en tu sistema.

- **Tutor: Verificar requisitos del curso** muestra qué falta.
- **Tutor: Ejecutar setup del curso** corre el script de configuración del curso, **solo después de pedirte confirmación** y de dejarte revisarlo.
- **Tutor: Abrir manual de configuración del curso** abre la guía paso a paso.
