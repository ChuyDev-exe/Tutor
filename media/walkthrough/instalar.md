# Instala un curso

Un curso es una carpeta con un archivo `curso.json`. Tienes dos formas de traerlo:

- **Desde un repositorio:** configura `tutor.repoCatalogUrl` con la URL de un `catalogo.json`, abre la vista **Buscar cursos y clases** y pulsa *Descargar*.
- **Desde una carpeta:** usa **Tutor: Importar curso desde carpeta…**.

Al instalarlo se crea tu carpeta de trabajo y un archivo `.tutor` con tu progreso. Las soluciones quedan fuera de tu carpeta hasta que resuelvas cada ejercicio.
